about=SmartModeler GIS is a QGIS 4-only visual Processing studio. It discovers installed algorithms, builds and runs typed acyclic workflows, imports and exports native .model3 models, and offers schema-validated iterative AI planning through local or remote providers. A separate Agent Workspace dock adds bounded read-only inspections and a supervised assistant: it can propose a workflow patch, a symbology intent, a safe live-signature Processing run, a run of your current workflow, or an explicitly reviewed cross-plugin action, but nothing takes effect until you click Apply or Run yourself. Results go to temporary layers and the last layer/model/style action can be undone. The assistant cannot run arbitrary code, plugin methods, expressions, URLs, paths, database actions or unreviewed algorithms. Its built-in reviewed OSM provider downloads one plain key/value filter from three pinned Overpass mirrors for the current canvas and creates a bounded temporary point, line, or polygon layer without QuickOSM, a raw query, an endpoint parameter, an API key, or a user path. A legacy reviewed QuickOSM adapter remains an explicit fallback. A reviewed 02viz adapter can open the installed visualization studio and render its offline smart chart suggestion for one selected vector layer; feature values stay local. Connected AI requests include the user's message, static instructions, and profile-enabled bounded metadata; SmartModeler does not automatically collect feature values, source paths, data-source URIs or credentials. Provider-reported input and output token usage is shown separately. Provider retention remains the provider's responsibility. API keys use password-free session memory or the optional encrypted QGIS vault. No pip dependencies are required.
